# ValkyriaBot Next Generation
## Work in Progress
Dear reader,

At this moment, we are working on ValkyriaBot Next Generation.
The original ValkyriaBot and it's sister application Serveerster will still work but will no longer be maintained by us.

This project has a few goals:
- Create an easy to install and feature-rich bot.
- Store data in MySQL instead of local .txt files in a config folder (exceptions shall be made)
- Make the bot more universal as to make updates easier to all instances
- Introduce auto-updating

All features from ValkyriaBot V9 are planned to be implemented in ValkyriaBot NG.
Including but not limited to:
- Bump reminder for Disboard
- Server stats
- Ticketing
- Moderation (kick, ban etc.)
- Confirmation system to assign member role
- Logging
- Roles
And much more...
